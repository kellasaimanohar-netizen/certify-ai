# Agent Audit V7 Dashboard

This is the frontend dashboard for **Agent Audit V7 — CertifyAI**. It provides a visual interface for running multi-source, standards-mapped, statistically honest pre-deployment certifications for Autonomous AI agents.

## Features

- **Visual Audit Runner:** Easily select targets, specify concurrency and variability runs, and launch audits.
- **Real-time Results:** View audit progress, trust scores, and certification tiers.
- **Detailed Findings:** Filter and search through detailed findings mapped to OWASP, NIST, EU AI Act, and DPDP standards.
- **Report Generation:** Download comprehensive JSON, SARIF, and HTML reports.

## Getting Started

Make sure you are running the backend API from the project root (`python backend.py`).

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at `http://localhost:5173`.
